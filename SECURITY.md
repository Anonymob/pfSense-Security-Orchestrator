# Security policy

This project is for defensive administration and authorized research in isolated labs or systems you are explicitly authorized to manage.

Please report vulnerabilities in this project privately to the maintainers before public disclosure. Do not include real firewall configuration backups, credentials, private keys, public IPs or customer data in issues or pull requests.

The current 0.1.0 release is an audit-first research prototype. It is not certified for production use and does not automatically make configuration changes. Treat the JSON advisory catalogue as a starting point; verify live vendor advisories before taking action.
